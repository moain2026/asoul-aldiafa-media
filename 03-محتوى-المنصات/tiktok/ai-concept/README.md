# ⚠️ محتوى مفهومي مولّد بالذكاء الاصطناعي — قهوجيات

هذه الأصول **مولّدة بالذكاء الاصطناعي** وليست تصويرًا حقيقيًا لطاقم أصول الضيافة.

**السبب:** لا توجد صور طاقم نسائي (قهوجيات) ضمن الأصول الحقيقية الـ50.
**الاستخدام المسموح:** محتوى مفهومي/إعلاني مع إفصاح واضح، أو كمرجع لجلسة تصوير نسائية حقيقية.
**الاستخدام الممنوع:** تقديمها كصور حقيقية لطاقم العلامة (خط أحمر في البريف).

التوصية القائمة: جلسة تصوير نسائية حقيقية لتغطية خدمة قهوجيات بمصداقية كاملة.
