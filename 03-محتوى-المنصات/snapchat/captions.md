# نصوص سناب شات

> نص بصري قصير؛ شريحة واحدة = فكرة واحدة. لا حشو ولا هاشتاقات.

## تسلسل من 4 لقطات لكل خدمة
- **صبابين قهوة:** «أول فنجال» ← «حضور يشرّف» ← «تفاصيل في وقتها» ← «راسلنا لمناسبتك في [المدينة]»
- **قهوجيين ومباشرين:** «ضيفك وصل» ← «واجبه حاضر» ← «وأنت مرتاح» ← «قهوجيين ومباشرين [المدينة]»
- **قهوجيات:** «أناقة هادئة» ← «ضيافة تعرف ذوقك» ← «خصوصية واهتمام» ← «قهوجيات [المدينة]»
- **ركن قهوة عربية:** «رائحة الهيل» ← «لمعة الدلّة» ← «دفء اللقاء» ← «ركن قهوة عربية [المدينة]»
- **ضيافة أعراس:** «ليلتكم» ← «فرحتكم» ← «وضيافة تشرّفكم» ← «أعراس [المدينة]»
- **ضيافة مؤتمرات:** «استقبال منظم» ← «حضور مهني» ← «إيقاع بلا تعطيل» ← «مؤتمرات [المدينة]»
- **تجهيز ضيافة حفلات:** «قبل أول ضيف» ← «كل شيء جاهز» ← «كل تفصيل في مكانه» ← «حفلات [المدينة]»

## المدن
يُصوّر تسلسل مستقل لكل من: جدة، ينبع، بدر بمحافظة المدينة، المدينة المنورة، مكة المكرمة.
