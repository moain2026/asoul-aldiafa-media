# أصول الضيافة · مستودع محتوى السوشل ميديا

مستودع الأصول والمحتوى الجاهز للنشر لعلامة **أصول الضيافة** (خدمات ضيافة سعودية فاخرة).

## البنية

```
01-الصور-القديمة/     ← الأصول الـ50 كما هي (+ الشعار والأيقونة)
02-الصور-الجديدة/     ← المعالجات بمقاسات 1x1 / 4x5 / 9x16 / 16x9 + ANALYSIS.md
03-محتوى-المنصات/
   instagram/  (posts, reels, stories, carousels)
   tiktok/     (videos, covers)
   snapchat/   (stories, spotlight)
   facebook/   (posts, cover, reels)
   x/          (posts)
   youtube/    (shorts, thumbnails)      + captions.md بكل مجلد
04-مراجع-الإلهام/     ← مراجع بصرية موثقة بروابط مصادرها
index.json            ← فهرس كل أصل (path, category, state, width, height, bytes, md5, ...)
ANALYSIS.md           ← تحليل تقني وحكم لكل أصل
```

## حقائق المصدر (متحقّق منها)

- الإجمالي المسحوب: **52 ملفًا** (50 صورة + `logo.webp` + `icon-gold.svg`).
- **الفريد: 44 صورة محتوى** (+ أصلا علامة). النسخ المكررة **6** في الصور:
  - `hero/hero-mobile` = `setups/setup-10`
  - `hero/hero-desktop` = `setups/setup-5`
  - `hero/hero-alt-1` = `products/product-9`
  - `hero/hero-alt-2` = `team/team-10`
  - `hero/logo` = `hero/logo-2` = `hero/logo-gold` (3 نسخ من الشعار)
  - ⇒ مجلد `hero/` بالكامل نسخ مكررة؛ لا يُعامَل كأصول جديدة.

## المعايير (ملزمة)

| البند | القيمة |
|-------|--------|
| المقاسات | 1:1 (1080×1080) · 4:5 (1080×1350) · 9:16 (1080×1920) · 16:9 (1920×1080) |
| الصيغة | WebP للصور · MP4 (H.264) للفيديو |
| الحجم | صورة ≤ 300KB · ريل ≤ 15MB |
| الخطوط | Amiri للعناوين · Tajawal للمتن |
| الألوان | ذهبي `#C5A059` · أسود عميق · لؤلؤي للنص |
| الشعار | 8–12% من العرض · زاوية ثابتة (أسفل يمين RTL) · هامش 4% · شفافية 60–75% |

## قاعدة اللغة (قرار علامة)

اكتب: **قهوجيين · صبابين · قهوجيات · مباشرين**. ممنوع الرفع بالواو (لا «قهوجيون»).
النبرة: فخامة هادئة واثقة، قصيرة، بلا مبالغة.

## المدن والخدمات

- المدن: جدة · ينبع · بدر · المدينة المنورة · مكة المكرمة
- الخدمات: صبابين قهوة · قهوجيين ومباشرين · قهوجيات · ركن قهوة عربية · ضيافة أعراس · ضيافة مؤتمرات · تجهيز ضيافة حفلات
- القاعدة: منشور/فيديو واحد لكل (خدمة × مدينة) — لا منشور عام.

## نموذج العمل

نطاق `base` يهيّئ البنية و`index.json` و`ANALYSIS.md`، ثم تعمل نطاقات المنصات بالتوازي على فروع `agent/<النطاق>`، وكل PR ≤ 400 سطر.
